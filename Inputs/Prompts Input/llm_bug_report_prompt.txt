### Промпт для генерации баг‑репортов
Вам предоставлен список не пройденных тест‑кейсов и детали их ошибок. Сформируйте баг‑репорт в формате JSON для каждой неудачной проверки, включив:
- "id": идентификатор тест‑кейса;
- "title": короткое описание проблемы;
- "description": подробное описание сбоя, шаги воспроизведения и наблюдаемое поведение;
- "severity": уровень серьёзности (Critical, Major, Minor);
- "status": установить значение "Open".
Верните массив объектов баг‑репортов.
